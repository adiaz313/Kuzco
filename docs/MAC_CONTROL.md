# Bounded Mac control

Kuzco accepts clear, whole-request commands for opening an app (existing), focusing an already-running app, changing the selected output device's volume by 10 percentage points, setting volume from 0–100%, and muting/unmuting. The new controls run before Llama. A fixed Swift AppKit helper focuses an exact running app name; another uses public CoreAudio properties and verifies changes. Unsupported output devices report failure.

Apple Music playback uses one compiled, fixed AppleScript adapter based on the installed Music.app scripting dictionary. It accepts operation and name as separate data arguments. It supports play/resume/pause/next/previous, exact named playlist, and exact named song in the user's Music library. A bare “play NAME” asks whether the user means a playlist or song because it could also be an artist or podcast. No script text comes from the user or model. Missing or duplicate items fail. Playback is verified after the native command returns; named requests also verify the selected playlist or track, and skips verify that the track actually changed. Music's documented back-track operation may restart the current song before moving to the previous one, so Kuzco makes at most one additional bounded back-track request if needed. macOS may ask to allow Kuzco Background to control Music under Privacy & Security → Automation.

Artist-wide and album-wide playback are deferred: selecting a single library track does not establish a reliable full artist/album queue. Apple Podcasts has no bundled scripting dictionary on the tested Mac; its App Intents do not provide a demonstrated supported direct third-party invocation path. Kuzco does not execute generic Shortcuts or simulate media keys. Named podcast, latest-episode, and podcast transport requests are therefore deferred. Display brightness is deferred because no suitable supported write interface was established. App quit is deferred until a trusted voice confirmation path can protect unsaved work. These requests should not be reported as completed.

Every new action is separately classified as a local action in the trusted policy. The current user utterance must match a narrow deterministic intent and exact arguments. Retrieved pages, documents, Skills, and model output cannot authorize it. The native helpers and fixed Music adapter are installed by `install_assets.py`; no Python package was added. Library names and app-use history are not stored in Kuzco memory or ordinary logs.
